
# STAR SURVIVOR 🚀

Raspberry Pi 4와 240×240 LCD를 활용한 우주 생존 아케이드 게임 프로젝트입니다.

## 1. 프로젝트 개요

- 게임 이름: STAR SURVIVOR (우주 생존 작전)
- 개발 환경: Python on Linux
- 하드웨어: Raspberry Pi 4, LCD-Joystick Module
- 디스플레이: 240×240 LCD
- 입력 장치: Joystick, GPIO Buttons

## 2. 게임 소개

플레이어는 우주선을 조종하여 소행성을 피하고 에너지 구슬을 수집합니다.

소행성과 충돌하면 체력이 감소하며, 생존 시간이 길어질수록 게임의 난이도가 증가합니다.

## 3. 주요 기능

- 조이스틱을 이용한 우주선 이동
- 소행성 생성 및 충돌 판정
- 에너지 구슬 수집 및 점수 획득
- 체력 및 보호막 시스템
- 난이도 증가 시스템
- 게임 일시정지 및 재시작
