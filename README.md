# STAR SURVIVOR 🚀

Raspberry Pi 4와 240×240 LCD 및 조이스틱을 활용하여 제작한 우주 생존 아케이드 게임 프로젝트입니다.

## 1. 프로젝트 개요

- **게임 이름:** STAR SURVIVOR (우주 생존 작전)
- **개발 환경:** Python 3.13 / Raspberry Pi OS (Linux)
- **하드웨어:** Raspberry Pi 4, LCD-Joystick Module
- **디스플레이:** 240×240 ST7789 LCD (SPI)
- **입력 장치:** GPIO 기반 조이스틱 및 A·B 버튼
- **개발 언어:** Python
- **주요 라이브러리:** Adafruit Blinka, Adafruit CircuitPython RGB Display, Pillow

본 프로젝트는 Pygame과 같은 게임 개발 라이브러리나 외부 게임 엔진을 사용하지 않고 구현하였습니다. GPIO 기반 입력 처리, 게임 루프, 객체 이동, 충돌 판정, 게임 상태 관리 및 LCD 화면 갱신 등의 핵심 기능을 Python으로 직접 구현하였습니다.

## 2. 게임 소개

STAR SURVIVOR는 우주선을 조종하여 소행성을 피하고, 다양한 아이템을 수집하며, 대형 소행성 보스를 처치하는 우주 생존 아케이드 게임입니다.

플레이어는 조이스틱을 이용해 우주선을 상하좌우 및 대각선으로 이동시킬 수 있습니다. 화면에는 별들이 아래쪽으로 흐르는 스크롤 배경을 구현하여 우주 공간을 비행하는 느낌을 제공합니다.

게임이 진행될수록 일반 소행성의 생성 개수와 이동 속도가 증가하며, 플레이어는 소행성을 피하면서 에너지 구슬을 수집하여 높은 점수를 획득하는 것을 목표로 합니다.

에너지 구슬 외에도 체력을 회복하는 아이템과 우주선의 공격 능력을 강화하는 아이템이 등장합니다. 무기 강화 아이템을 획득하면 총알의 발사 개수와 공격력이 증가하여 이후 보스전을 더욱 유리하게 진행할 수 있습니다.

일정 레벨에 도달하면 대형 소행성 보스가 등장하며, 플레이어는 일반 소행성을 회피하는 동시에 자동으로 발사되는 총알을 이용하여 보스를 처치해야 합니다. 보스를 처치하면 다음 레벨로 진입하여 게임을 계속 진행할 수 있습니다.

또한 일정 시간 동안 소행성 충돌을 방어하는 무적 보호막 스킬을 사용할 수 있으며, 스킬의 지속 시간과 재사용 대기시간을 고려하여 생존 전략을 세울 수 있습니다.

게임 종료 시 최종 점수와 도달 레벨, 최고 점수 및 최고 기록 달성 시각이 표시됩니다. 최고 기록은 파일에 저장되어 프로그램을 종료한 이후에도 유지됩니다.

## 3. 게임 규칙 및 조작 방법

### 게임 규칙

**생존 및 체력**

- 게임 시작 시 하트 3개가 주어집니다.
- 소행성과 충돌하면 하트가 1개 감소합니다.
- 충돌 후 1초 동안 무적 상태가 적용되며, 우주선이 깜빡이는 효과로 표시됩니다.
- 체력 회복 아이템을 획득하면 하트가 1개 회복됩니다.
- 최대 체력은 하트 3개로 제한됩니다.
- 하트가 모두 소진되면 GAME OVER 화면으로 전환됩니다.

**아이템 및 점수**

- 에너지 구슬을 수집하면 100점을 획득합니다.
- 체력 회복 아이템은 일반 레벨 중 3의 배수에 해당하는 레벨에서 등장합니다.
- 무기 강화 아이템은 레벨 2부터 보스전을 제외한 각 레벨에서 등장합니다.
- 체력 회복 및 무기 강화 아이템은 등장 후 5초 동안 획득하지 않으면 사라집니다.
- 무기 강화 아이템을 획득하면 무기 레벨이 1 증가합니다.
- 무기 레벨은 최대 6까지 강화할 수 있습니다.

**레벨 및 보스전**

- 일반 레벨에서는 20초 동안 생존하면 다음 레벨로 진입합니다.
- 레벨이 상승하면 일정 난이도까지 소행성의 최대 생성 개수와 이동 속도가 증가합니다.
- 레벨 상승 시 상단 레벨 표시가 일시적으로 확대되고 깜빡이는 효과가 적용됩니다.
- 레벨 5, 10, 15, 20 등 5레벨마다 대형 소행성 보스가 등장합니다.
- 보스전에서는 우주선의 총알이 자동으로 발사됩니다.
- 보스전 중에도 일반 소행성이 등장하므로 지속적으로 회피해야 합니다.
- 보스전 중에는 신규 아이템이 생성되지 않습니다.
- 보스전에는 시간 제한이 없으며, 보스를 처치해야 다음 레벨로 진입할 수 있습니다.
- 보스를 처치하면 500점을 획득합니다.
- 이후 등장하는 보스의 체력은 점차 증가합니다.
- 게임 레벨에는 최대 제한이 없으며, 생존하는 동안 계속 진행할 수 있습니다.

**무적 보호막 스킬**

- A 버튼을 사용하여 5초 동안 무적 보호막을 활성화할 수 있습니다.
- 무적 스킬은 발동 시점부터 30초의 재사용 대기시간이 적용됩니다.
- 보호막 활성화 중에는 일반 소행성과 충돌해도 하트가 감소하지 않습니다.

**일시정지 및 게임 종료**

- B 버튼으로 게임을 일시정지하거나 재개할 수 있습니다.
- 일시정지 중에는 게임 객체의 이동과 각종 게임 타이머가 함께 정지합니다.
- GAME OVER 화면에서는 최종 점수, 도달 레벨, 최고 점수 및 최고 기록 달성 시각이 표시됩니다.
- 기존 최고 점수를 초과하면 최고 기록이 갱신됩니다.
- GAME OVER 화면에서 A 버튼을 누르면 게임을 다시 시작할 수 있습니다.

### 아이템 종류

| 아이템 | 외형 | 효과 |
|---|---|---|
| 에너지 구슬 | 청록색 구슬 | 점수 100점 획득 |
| 체력 회복 아이템 | 붉은색 하트 | 체력 1 회복 |
| 무기 강화 아이템 | 보라색 구슬과 노란색 번개 | 무기 레벨 1 증가 |

### 무기 강화 단계

| 무기 레벨 | 발사 개수 | 총알당 공격력 | 발사당 최대 피해량 | 총알 색상 |
|---|---:|---:|---:|---|
| Lv.1 | 1 | 1 | 1 | 노란색 |
| Lv.2 | 2 | 1 | 2 | 노란색 |
| Lv.3 | 3 | 1 | 3 | 노란색 |
| Lv.4 | 3 | 2 | 6 | 청록색 |
| Lv.5 | 3 | 3 | 9 | 보라색 |
| Lv.6 | 3 | 4 | 12 | 분홍색 |

무기 레벨이 상승함에 따라 총알의 발사 개수, 공격력, 크기 및 색상이 변경됩니다. 총알은 보스전에서만 자동으로 발사되며, 일반 소행성은 공격 대상이 아닌 회피 대상으로 유지됩니다.

### 조작 방법

| 입력 | 기능 |
|---|---|
| 조이스틱 상하좌우 | 우주선 이동 |
| 조이스틱 대각선 | 대각선 이동 |
| A 버튼 (시작 화면) | 게임 시작 |
| A 버튼 (게임 진행 중) | 무적 보호막 스킬 발동 |
| A 버튼 (GAME OVER) | 게임 재시작 |
| B 버튼 (게임 진행 중) | 일시정지 및 재개 |
| 별도 입력 없음 (보스전) | 총알 자동 발사 |

## 4. 주요 구현 기능

### 게임 진행 및 상태 관리

- 시작 화면 및 A 버튼을 통한 게임 시작
- 게임 루프 및 게임 진행 상태 직접 구현
- 전체 생존 시간 및 개별 레벨 진행 시간 관리
- 시간 기반 일반 레벨 진행 및 보스 처치 기반 레벨 진행
- 충돌에 따른 하트 감소 및 GAME OVER 처리
- B 버튼을 이용한 일시정지 및 재개
- 일시정지 시 게임 객체 이동 및 각종 타이머 정지
- 게임 재시작 시 점수, 목숨, 레벨, 소행성, 아이템, 무기, 총알, 보스 및 스킬 상태 초기화

### 우주선 및 충돌 시스템

- 조이스틱을 이용한 상하좌우·대각선 이동
- 대각선 이동 시 속도 보정
- 화면 경계를 벗어나지 않도록 이동 범위 제한
- 우주선과 일반 소행성 간 충돌 판정
- 우주선과 아이템 간 획득 판정
- 사각형과 원형 객체의 기하학적 충돌 판정
- 충돌 후 1초 무적 시간 및 우주선 깜빡임 효과
- 무적 상태에 따른 충돌 피해 방지
- 보스전 진입 및 종료에 따른 우주선 이동 범위 변경

### 일반 소행성 및 난이도 시스템

- 소행성의 무작위 생성 및 이동
- 수직·대각선 방향 이동
- 화면 밖으로 벗어난 소행성 제거
- 게임 레벨에 따른 소행성 생성 주기 및 이동 속도 변경
- 소행성 최대 생성 개수 및 이동 속도에 상한 설정
- 무한 레벨 진행에 따른 과도한 난이도 상승 및 성능 저하 방지
- 보스전 중 소행성 생성 위치 및 난이도 조정
- 레벨업 시 상단 레벨 표시 확대 및 깜빡임 효과

### 아이템 시스템

- 공통 Item 클래스를 기반으로 한 아이템 상속 구조
- 에너지 구슬, 체력 회복 아이템 및 무기 강화 아이템 구현
- 아이템의 무작위 생성 위치 및 이동 속도 설정
- 아이템 이동, 화면 이탈 및 유지 시간 관리
- 우주선과 아이템 간 충돌을 통한 획득 판정
- 아이템 종류에 따른 점수 증가, 체력 회복 및 무기 강화 처리
- 특수 아이템의 레벨별 중복 생성 방지
- 최대 체력 및 최대 무기 레벨 제한
- 보스전 진입 시 기존 아이템 제거 및 신규 아이템 생성 중단
- 보스 처치 후 아이템 생성 재개

### 무기 및 총알 시스템

- 총알의 위치, 이동 속도, 공격력, 크기 및 색상 관리
- 일정 시간 간격을 통한 총알 자동 발사
- 총알의 이동 및 화면 이탈 처리
- 무기 강화 아이템을 통한 6단계 무기 강화 시스템
- 무기 레벨에 따른 총알 발사 개수 및 공격력 변경
- 무기 레벨에 따른 총알 크기 및 색상 변경
- 화면 하단 무기 레벨 및 강화 게이지 표시
- 최대 무기 레벨 도달 시 WEAPON MAX 표시
- 소행성 충돌 시 기존 무기 강화 상태 유지
- 게임 재시작 시 무기 레벨 초기화
- 보스전에서만 자동 발사 활성화

### 대형 소행성 보스 시스템

- 5레벨마다 대형 소행성 보스 등장
- 일반 소행성과 구분되는 독립적인 Boss 클래스 구현
- 보스의 위치, 크기, 현재 체력 및 최대 체력 관리
- 첫 번째 보스 체력 100 및 이후 등장 횟수마다 체력 50 증가
- 보스 체력 및 HP 게이지 표시
- 총알의 사각형 영역과 보스의 타원형 영역을 이용한 충돌 판정
- 총알 공격력에 따른 보스 체력 감소
- 충돌한 총알 제거 및 보스 체력 게이지 갱신
- 보스전 중 일반 레벨 진행 타이머 정지
- 보스전 중 우주선 이동 범위 및 일반 소행성 생성 위치 조정
- 보스 처치 시 500점 지급 및 다음 레벨 진입
- 보스 처치 후 자동 발사 중단 및 일반 게임 상태 복구
- 일반 레벨과 보스전이 반복되는 게임 진행 구조 구현

### 점수 및 최고 기록 저장 시스템

- 에너지 구슬 획득 시 100점 추가
- 대형 소행성 보스 처치 시 500점 추가
- 점수 표시 영역 실시간 갱신
- GAME OVER 화면에서 최종 점수 및 도달 레벨 표시
- 기존 최고 점수와 현재 점수 비교
- 최고 점수 갱신 시 NEW HIGH SCORE 안내 표시
- 최고 점수, 달성 레벨 및 달성 시각을 JSON 파일로 저장
- 프로그램 재실행 시 기존 최고 기록 불러오기
- 파일 입출력 및 잘못된 기록 데이터에 대한 예외 처리
- 임시 파일을 이용한 최고 기록 저장 처리

### 무적 스킬 및 쿨타임 시스템

- A 버튼 입력을 통한 무적 보호막 활성화
- 스킬 발동 시 5초 동안 일반 소행성 충돌 피해 방지
- 보호막 활성화 중 우주선 색상 변경 및 원형 보호막 표시
- 스킬 발동 시점부터 30초의 재사용 대기시간 적용
- 쿨타임 중 스킬 재사용 제한
- 버튼 입력 상태 비교를 통한 중복 발동 방지
- 우측 하단 원형 방패 아이콘을 통한 스킬 상태 표시
- 쿨타임 중 아이콘 색상 변경 및 남은 시간 숫자 표시
- 남은 쿨타임을 1초 단위로 갱신
- 쿨타임 종료 시 방패 아이콘을 사용 가능 상태로 복구
- 일시정지 시 스킬 지속 시간 및 쿨타임 정지

### GPIO 입력 및 하드웨어 제어

- Raspberry Pi GPIO를 이용한 조이스틱 방향 입력 처리
- A·B 버튼의 디지털 입력 상태 확인
- Active Low 방식의 입력 처리
- SPI 통신을 이용한 ST7789 LCD 제어
- LCD 초기화 및 백라이트 제어
- 프로그램 종료 시 GPIO 및 LCD 자원 정리

### LCD 화면 출력 및 최적화

- ST7789 LCD를 이용한 240×240 화면 출력
- Pillow 기반 화면 버퍼 생성 및 그래픽 출력
- 별 배경 스크롤 효과

- 우주선을 게임 객체보다 앞쪽에 표시하여 객체가 겹치는 상황 처리

- 겹치는 갱신 영역 병합을 통한 불필요한 LCD 전송 최소화
- 화면 버퍼 재사용을 통한 반복적인 이미지 생성 최소화
- 폰트 객체 재사용을 통한 불필요한 반복 연산 감소
- 하트, 점수, 레벨, 무기 강화 게이지 및 스킬 아이콘 영역의 개별 갱신

- 일시정지 시 중앙에 PAUSED 및 재개 안내 문구 표시
- 게임 재개 시 일시정지 이전 화면 복구

## 6. 설치 및 실행 방법

### 1) 실행 환경 준비

Raspberry Pi 4에 Raspberry Pi OS를 설치하고, LCD-Joystick Module을 연결합니다.

게임 실행을 위해 Raspberry Pi의 SPI 인터페이스가 활성화되어 있어야 합니다.

```bash
sudo raspi-config
```

`Interface Options → SPI → Enable`을 선택합니다.

SPI 장치 확인:

```bash
ls /dev/spidev*
```

### 2) 저장소 복제

```bash
git clone https://github.com/sanghyeok8473/star-survivor-raspberry-pi.git
cd star-survivor-raspberry-pi
```

### 3) Python 가상환경 생성 및 활성화

```bash
python3 -m venv .venv --system-site-packages
source .venv/bin/activate
```

### 4) 패키지 설치

```bash
python -m pip install -r requirements.txt
```

### 5) 게임 실행

```bash
python main.py
```

LCD에 시작 화면이 표시되면 A 버튼을 눌러 게임을 시작합니다.

게임을 종료하려면 터미널에서 `Ctrl + C`를 누릅니다.

※ 본 프로젝트는 Raspberry Pi의 GPIO 및 SPI 하드웨어를 사용하므로, 해당 장치가 연결되고 설정된 환경에서 실행해야 합니다.

## 7. 향후 개선 가능 사항

현재 게임의 핵심 기능인 우주선 이동, 소행성 회피, 아이템 수집, 무기 강화, 반복 보스전, 무적 보호막, 일시정지 및 최고 기록 저장 기능을 구현하였습니다.

추가적인 시각적 완성도 향상을 위해 다음과 같은 개선을 고려할 수 있습니다.

- 우주선, 일반 소행성 및 대형 소행성 보스의 이미지 기반 그래픽 적용
- 에너지 구슬, 체력 회복 아이템 및 무기 강화 아이템의 시각적 디자인 개선
